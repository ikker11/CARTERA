# Cartera 💚

App personal de economía para iPhone con **Nova**, un asistente que aprende de tus gastos.
Todos los datos se guardan solo en tu iPhone; nada se envía a ningún servidor.

## Qué hace
- Ingresos y gastos con categorías (Comida, Gasolina, Cenas, Ocio, Microgastos, Fumar…) y categorías propias.
- Gastos e ingresos **fijos**, que se apuntan solos el día que toca.
- Gastos **fraccionados**: importe total, meses y fecha del primer pago, con el progreso de las cuotas.
- **Metas de ahorro**, con lo que necesitas apartar cada mes.
- **Escáner de tickets**: haces una foto y Nova lee el importe, la fecha y el comercio.
- **Nova** clasifica tus gastos, aprende de tus correcciones, te avisa de lo que se dispara, te dice dónde recortar y te aconseja antes de una compra.
- Código PIN, modo oscuro, funciona sin conexión y permite copias de seguridad.

## Publicarla con GitHub Pages
1. Sube todos los archivos de esta carpeta al repositorio.
2. Ve a **Settings → Pages → Branch: `main` / `(root)` → Save**.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/` en **Safari** desde el iPhone.
4. Pulsa **Compartir → Añadir a pantalla de inicio**.

## Actualizar
Cuando cambies archivos, sube también `sw.js` con la versión aumentada (`cartera-v2`, `cartera-v3`…) para que el iPhone descargue la nueva versión.
